# BunnyHub

The source for **BunnyNexus**, a Discord bot for study tracking, free-game alerts and server moderation, and
**BunnyHub**, the Java command framework it runs on.

Everything lives in [`BunnyHub/`](BunnyHub/): see its [README](BunnyHub/README.md) for features, setup and
deployment.

- **Language:** Java 21
- **Discord library:** JDA 6
- **Database:** MongoDB (replica set)
- **Hosting:** Docker on Railway

The older TypeScript GBF handler and its npm package (`gbfcommands`) are no longer maintained here.
